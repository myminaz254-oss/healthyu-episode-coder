# Agent Instructions for Episode Coder Build

After every meaningful step, append a timestamped one-line entry to PROGRESS_LOG.md.

Format: `YYYY-MM-DD HH:MM - <step description>`

Example:
```
2026-09-02 14:30 - Created repository scaffold and copied data files
2026-09-02 14:45 - Implemented catalog.py with GDL-027/AB30 validation
```

This file must be created BEFORE any code is written, per BRIEF.md "Agent setup" section.
